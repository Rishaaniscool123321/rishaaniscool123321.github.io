# Rishaan Kumar Aggarwal — NFC Profile Site

This folder is ready for GitHub Pages.

## Publish it on GitHub Pages

1. Sign in to the GitHub account `Rishaaniscool123321`.
2. Create a new **public** repository named exactly:
   `rishaaniscool123321.github.io`
3. Open the repository and choose **Add file → Upload files**.
4. Upload the contents of this folder:
   - `index.html`
   - `Rishaan-Kumar-Aggarwal.vcf`
   - `.nojekyll`
   - `README.md`
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
8. Save and wait for GitHub Pages to finish publishing.

Your public website should be:

https://rishaaniscool123321.github.io/

## Put it on the NFC card

Write this URL to the NFC card:

https://rishaaniscool123321.github.io/

Use the NFC-writing app supplied with the card or another NFC writer app.
Select the URL/website record type, paste the address, and write it to the card.

title, and birthday. Anyone who has the public website link can download those
details. The page includes a `noindex` instruction to discourage search-engine
indexing, but the website is still public to anyone with the URL.
